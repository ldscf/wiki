科幻小说《黑云》(The Black Cloud)是英国天体物理学家弗雷德·霍伊尔爵士(Sir Fred Hoyle)1957 年所著。

它描述了进入太阳系的巨大气体云，似乎想通过阻挡太阳来摧毁地球上的大部分生命。

> 

这部小说是“有史以来最伟大的科幻小说之一”。

*牛津大学教授、英国进化生物学家和作家理查德·道金斯(Richard Dawkins)* 

> ![Fred_Hoyle.jpg](https://mwbbs.eu.org/wiki/images/f/ff/Fred_Hoyle.jpg)

弗雷德·霍伊尔爵士曾担任英国皇家天文学会会长，创建了剑桥大学的理论天文研究所，写下多部学术专著、科普读物、科幻小说、电视剧，以及一部自传，被认为是 20 世纪有影响力的科学家之一。

著名的“大爆炸”(Big Bang)一词就是其在 BBC 的一次广播节目中首先使用的。霍伊尔爵士创建了稳恒态宇宙模型，并不相信大爆炸模型。为此还精心设计了一个实验以证大爆炸模型之伪，但实验结果倾向于支持大爆炸模型，霍伊尔爵士很绅士的发表了该结论。

```
　　1964年1月7日，格林威治时间早上8点钟，在英格兰，冬天的太阳刚刚升起。整个岛上的人都呆在供暖不足的屋子里瑟瑟发抖，读着晨报，享用早餐，同时抱怨着天气。老实说，最近的天气是挺糟糕的。

```

```
　　然后这条本初子午线走向赤道通过法属苏丹、阿善提地区和黄金海岸——在那里，沃尔特河沿岸，一座座崭新的铝厂拔地而起。此后它进入了广阔的海洋，一直延伸到南极洲，有十几个国家的探险队在那里一起工作。
```
```
　　在这条子午线的东边，直到新西兰，阳光明媚。而在澳大利亚，夜幕已经降临。长长的阴影投射在悉尼的板球场上，新南威尔士州和昆士兰州的比赛刚刚结束。在爪哇，渔民正在忙着准备晚上出海作业。
```
```
　　在太平洋那广阔无垠的海域、在美国、在大西洋，大部分地区都笼罩在夜幕之中。纽约正是凌晨三点，尽管有积雪和从西北刮来的冷风，这座城市依旧灯火通明，车流不息。此刻，地球上没有哪个地方比洛杉矶更热闹非凡。午夜十二点，这里的夜晚才刚刚开始，公路上车流不息，餐馆座无虚席。
```

```
　　一百二十英里以南的帕洛马山上，天文学家们已经开始了夜间的观测。尽管夜色明朗，从地平线到天顶星星闪烁，但是从职业天文学家的角度看，观测条件并不好，“视宁度”很差——因为高空中有很大的风。所以没人会在意放下手边的事情，去吃点儿夜宵。傍晚时分，他们就发现今晚的观测条件相当的不妙，于是约定在 48 英寸施密特望远镜的穹顶下小聚。

```

```

```

```
　　纳特看了看大家很惊讶的表情，说：“你们不这样吃沙丁鱼吗？哦，那么你们是不知道沙丁鱼真正的吃法，试一下，你们会喜欢的。”
```

```
　　然后，为了制造一点效果，他补充道：“我想我进来的时候闻到了臭鼬的气味。”
```
```
　　“最好带着你那盘杂拌走开，纳特。” 罗杰斯说。
```

```
　　笑声平息后，吉姆问到：
```

```
　　“你们听说两周前那只臭鼬的事了吗？它在 200 英寸望远镜的进气口附近放出臭气。在有人停下排风扇之前那个地方已经气味弥漫，臭气浓度高达百分之几百，那一定是那两百个人在参观时最深刻的一幕。
```

```
　　“幸运的是我们没有收入场费，”爱默生忍俊不禁，“否则天文台还得赔偿损失。”
```

```
　　在回去 18 英寸施密特望远镜的路上，詹森停下来聆听北面山区森林中发出的风声，与他家乡如此相似的山丘，让他的乡愁抑制不住，渴望与家人再团聚，渴望与格里塔在一起。纳特今年 24 岁，已经在美国学习了两年。他继续往回走，试图忘掉刚才不明智的想法。老实说他没什么理由沮丧，每个人对他都很友善，而且他的工作很理想，适合一个新手。
```
```
　　天文学对初学者是宽容的，有许多能带来重要成果而且不需要丰富经验的工作可以做，詹森就是这些新手中的一个。他正在搜索超新星，也就是那些以惊人的剧烈程度爆发的恒星。在在接下来的一年里，他有希望找到一两颗。由于无法预测超新星爆发何时发生，也无法预测爆发的恒星位于天空中的哪个位置，唯一能做的就是夜复一夜、月复一月地持续拍摄整个天空。总有一天，他会走运的。
```
```
　　如果他真的在太空中不算太遥远的地方发现了一颗超新星，那时会有一些富有经验的“老手”接替他的工作，届时，200 英寸望远镜的全部威力将被用来揭示这些遥远恒星的秘密，而不是 18 英寸施密特望远镜。
```
```
　　但无论如何，他都将拥有首次发现的荣誉。在世界上最大的天文台的工作经验和获得的赞誉，回国后会对他大有裨益——他很有希望找到一份好工作，然后和格丽特结婚。那么在这个世界上他还有什么可以让他闷闷不乐的呢？他暗骂自己是个傻瓜，竟然为了一阵山风而心神不宁。
```
```
　　现在他已经在那台小型施密特望远镜的屋子里了。他首先查看了一下他的笔记，找到天空中下一个要拍摄的区域。
```
```
　　然后他设定好合适的方向，猎户座以南——寒冬腊月，这是一年中唯一能观测到这部分天空的季节。接下来是开始曝光，然后剩下的时间就是等待，直到闹钟响起。这段时间只能在黑暗中坐下来等，除了在那左思右想，没有什么事情可做。
```
```
　　詹森一个接着一个的爆光，一直工作到凌晨，做完了这事他的工作并不算结束。他还要冲洗完今天晚上拍下的底片，干这事需要仔细，一个失误他的辛苦就白费了，没有办法重头再来。
```
```
　　所以通常情况下，他会放下这最后也是最不好做的工作。一般他先回宿舍，睡上五六个小时，中午起来吃早餐，也只有到那时，他才会去冲洗底片。但是今天是他忙碌的最后一天，月亮到傍晚就出来了，这意味着为期两周的观测要结束了，因为超新星的观测在晚上有月亮的半个月时间里是没办法进行的——这不难理解，月亮的光线很强，以至于他用于感光的敏感底片会形成雾翳，失去作用。
```
```
　　因此在这个特殊的日子里，他将回到一百二十五英里远的帕萨迪纳天文台的办公室里。去那儿的班车11点半发车，在此之前他必须处理好底片，詹森决定马上就做这件事，那么他还可以睡上四个小时，快点吃早餐，然后就得准备收拾东西回城里。
```
```
　　事情按计划做完了，但也把坐在去往北方班车上的这个年青小伙子累坏了。车上有三个人：司机、罗杰斯和詹森，爱默生还得要忙两个晚上才能回去。汽车在几英里长的橘子园环绕的公路上飞驶，但詹森却睡着了，他的朋友们在漫天风雪的挪威知道了一定很惊讶。
```
```
　　* * *
```
```
　　詹森起得很晚，直到十一点钟，他才赶到天文台的办公室。有大约一个星期的工作在等着他，检查最后两个星期的底片。他所要做的就是对比最新观测结果与上个月的有什么不同。而这要求他分别查看每一寸的天空。
```
```
　　因此在一月上旬，1964年1月8日，詹森在天文台的地下室安装一个“闪动器”。顾名思义，这个“闪动器”的装置能让他先看第一张底片，再看第二张，然后再回到第一张，然后相当快速的交替。这么做可以让星星在两张底片拍摄期间发生的一些可查觉的变化形成一个振动、闪烁的光点，而另外绝大多数的恒星因为没有变化而保持原样。用这种方法才可能在一万多颗恒星里面容易些地挑出来一颗变化的恒星。因为不用一颗一颗的去比较，因此大大降低了工作强度。
```
```
　　制作闪动器上使用的底片需要高度小心，不仅仅需要使用相同的仪器，还要尽可能的在观测天文学家能做到的情况下，在相同的环境下拍摄，相同的爆光时间和显影程度。这也说明了为什么詹森要那么小心的处理曝光和冲洗。
```
```
　　他现在遇到的问题是爆发的星并不是产生变化的唯一种类。尽管绝大多数的星星没什么变化，但还是有一些种类的星星会在闪动器上产生所谓的振动。这样普通振动的星星要检查分离出来并且从搜索中排除。詹森估计他找到一颗超新星需要检查并排除一万左右普通振动的星星里面绝大部分。通常他经过很短的检测就可以否定一个振动的星，但有时候也会遇到些困难。那时他会去查一个星表，这意味着要确定这个有问题的星的准确位置。因此所有的一切，在他处理完他积累下来的底片前，有相当多的工作要做——这些工作是相当乏味的。
```
```
　　在一月十四日他几乎看完了积累的大部分底片，晚上他决定回天文台。他在加州理工学院呆了一下午，那儿有个有趣的关于螺旋星系的专题讨论会，会后他们又讨论了好一阵子，甚至他和他的朋友们在整个晚餐的过程中以及在回到天文台的路上也在讨论。他估计他只剩下最后一批底片了，就是一月七日晚上拿过来这批。
```
```
　　他完成了第一组，事实上这是一个费力不讨好的工作。还是老样子，每一个可能的情况都是普通的、已经知道的振动。他想，做完这事后他应该感到高兴，这里的工作结束后回到山上看望远镜也比弯腰伏在这个该死的仪器的目镜上弄伤他的眼睛强。
```
```
　　他打开开关，第二对底片在视野中中闪动。马上詹森就笨手笨脚的把底片从机器中抽出来，把它们拿到灯光下看了好长时间，然后把底片放回到闪动器上再次查看。在一片星辰密布区域有一大块几乎刚好是圆形的暗斑，但是他发现环绕这块暗斑周围的星星是那么的令他惊奇，它们在那同时振动、闪烁。这是为什么呢？他想不出来满意的答案，因为他以前从来没有见过和听到类似的事。
```
```
　　詹森发现他没有办法继续工作了，他对这个不同寻常的发现非常激动，他得马上跟别人谈谈这事。这个理所当然的人选就是马洛博士，一个资深的长者。很多天文学家专注于一个领域或有关他们课题方面的一些知识，马洛除了关注自己的领域，他还有超过其它人所不及的广博知识，也许正因为这才会让他比别人少犯错误。他不管白天黑夜随时都准备好跟别人谈论天文学，他对任何人都非常热情，不管是像他自己这样著名的科学家，还是一个初出茅庐的年青人。因此很自然的，詹森想告诉马洛他不同寻常的发现。
```
```
　　他小心翼翼的把两张有问题的底片放到一个盒子里，关掉地下室的设备电源和灯。然后来到图书馆外面的布告栏，查阅观测名单。他看到的结果让他很满意，马洛博士没有出去，也在帕洛马或威尔逊山。然而，当然了，他也许晚上出去了。詹森很走运，电话一下就接通了，马洛在家。当他讲了他所遇到的一些不寻常的事情后，马洛说：
```
```
　　“现在过来吧，纳特，我等你。不，这没关系，我没什么特别的事情。”
```
