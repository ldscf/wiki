```
　　《百万英镑》(The Million Pound Note)是美国作家马克·吐温(Mark Twain, 1835/11/30 - 1910/4/21)创作的中短篇小说，发表于1893年。
```
```
　　故事发生在十九世纪末的英国，亨利·亚当斯是美国旧金山证券交易所的交易员，小伙子聪明能干，如无意外，未来将会成长为投资顾问、证券经纪人。但机缘巧合之下，落魄来到英国，获得了一张百万英镑的支票，从而引发了一系列令人啼笑皆非的故事。
```
```
　　马克·吐温以其略带夸张的讽刺与幽默，深刻揭露了19世纪英国社会的拜金主义思想，把上至王公贵族、下至平民百姓，在金钱面前的丑态刻画得惟妙惟肖，将金钱对资本主义社会的污染乃至人性的歪曲勾勒得入木三分。（咳咳，这个应该是上学时候写的中心思想）
```
```
　　据说这部作品是马克·吐温投资白银股票失败后，为了偿还债务，迫于生计，只能重操旧业写出来的。
```
```
　　看这本书，还有八十天环游地球等欧美作品，感触最深的竟然是诚信，以及对承诺、规则的遵守。我不知道现在这种品行还有没有了——至少那个时候有。
```
```
　　马克·吐温是美国批判现实主义文学的奠基人，2006年，马克·吐温被美国的权威期刊《大西洋月刊》评为影响美国的100位人物第16名。
```

### 关于马克吐温 & 哈雷彗星

1835年11月16日，哈雷彗星回归，这是地球上几乎大多数的人、不用借助天文望远镜、一生中只能见一次的彗星，每次回归周期是76.1年。那一年，十几天后，马克吐温诞生于密苏里州佛罗里达的一个小乡村。他还曾经预言，将跟随着哈雷彗星下一次出现而去。1910年的4月20日，哈雷彗星拖曳着明亮的彗尾闪过天空，一天以后，马克.吐温心脏病发作而离开了人间。
