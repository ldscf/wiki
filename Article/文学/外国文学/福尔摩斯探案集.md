```
　　夏洛克·福尔摩斯（Sherlock Holmes）是由19世纪末英国侦探小说家阿瑟·柯南·道尔（Arthur Conan Doyle）所塑造的一个才华横溢的侦探，住在伦敦贝克街 221 号 B。
```
```
　　福尔摩斯善于通过观察与演绎推理和法学知识来解决问题，常能够足不出户就可以解决很多疑难问题。
```

![伦敦贝克街221号B.jpeg](https://mwbbs.eu.org/wiki/images/5/5f/伦敦贝克街221号B.jpeg)
```
　　福尔摩斯系列小说一共 4 篇中篇、56 篇短篇。最早两篇分别是 1887 年《毕顿圣诞年刊》刊登的《血字研究》及 1890 年理本科特月刊登出的《四签名》。而 1891 年开始在《海滨杂志》(The Strand Magazine)上的系列短篇小说连载，使福尔摩斯的受欢迎程度爆炸性的水涨船高。
```
```
　　1894 年柯南·道尔决心停止写作，因此在《最后一案》中，让福尔摩斯坠入深渊身亡。此举令读者大哗，有超过两万人取消订阅连载故事的《海滨杂志》，连他母亲也提出抗议。
```
```
　　直到 1927 年，柯南·道尔先生终于在《空屋》中安排福尔摩斯归来，写出续集《归来记》、《最后致意》、《新探案》等。
```
```
　　所有故事中，几乎全部都是以福尔摩斯的朋友及传记作家约翰·H·华生医生的角度叙述的。只有两篇(《狮鬓毛》与《皮肤白化的士兵》）是由福尔摩斯亲自叙述、两篇是由第三人称角度撰写。故事的发生年代大约集中在 1875~1907 年，最后一案发生在 1914 年。
```
```
　　《福尔摩斯探案集》可谓是开辟了侦探小说历史“黄金时代”的不朽经典，风靡全世界，是历史上最受读者推崇的侦探小说。> ![ConanDoyle.jpeg](https://mwbbs.eu.org/wiki/images/5/5f/ConanDoyle.jpeg)
```
```
　　阿瑟·柯南·道尔（Arthur Conan Doyle，1859 年 5 月 22 日 ~ 1930 年 7 月 7 日），生于苏格兰爱丁堡，因塑造了成功的侦探人物——夏洛克·福尔摩斯而成为侦探小说历史上最重要的作家之一。
```
```
　　代表作有《福尔摩斯探案集》（包括《血字的研究》《四签名》《巴斯克维尔的猎犬》等）。
```
```
　　柯南·道尔对侦探小说的贡献是巨大的。其小说的故事结构、推理手法和奇巧的构思都给该类题材的小说树立了范本，将侦探小说推向了一个崭新的时代，是当之无愧的文学大师。
```
