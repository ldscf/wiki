```
　　冬至，又称“日短至”、“日南至”等，是二十四节气中一个重要的节气，也是中国民间的传统祭祖节日，而其中最高的祈祷仪式则是天子举行的祭天礼，每年冬至，由皇帝代表万民苍生向上天祈求天下安泰、万物丰收。
```
```
　　冬至是四时八节之一，被视为冬季的大节日，在古代民间有“冬至大如年”的讲法。冬至节气的到来标示着北半球各地这天太阳高度最小、白昼最短。
```
```
　　在中国北方，每年冬至日，有吃饺子的习俗。中国北方地区在这天要吃饺子因为饺子有“消寒”之意，至今民间还流传着“冬至不端饺子碗，冻掉耳朵没人管”的民谚。
```
```
　　冬至过后，中国各地气候都将进入一个最寒冷的阶段，也就是人们常说的“数九寒天”了。人们要根据天气情况及时增添衣物，注意保暖；室内要通风换气，减少和抑制病菌病毒繁殖；多吃补益身体的食物，如莲子、芡实、薏仁、赤豆、大枣、银耳等。
```
```
　　所谓“数九”，即是从冬至算起，每逢壬日也就是九天算一“九”。民间流传着的歌谣是这样说的：“一九、二九不出手，三九、四九冰上走，五九、六九沿河看柳，七九河开，八九燕来，九九加一九，耕牛遍地走。”从“一九”数到“九九”，冬寒就变成春暖了。> 白昼最是时光短，灌汤水饺暖夜长
```
