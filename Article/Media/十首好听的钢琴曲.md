### 天空之城(Castle In The Sky)
```
　　古老帝国拉比达是一座漂浮在空中的巨大的机器岛，传说那里已经无人居住，蕴藏着巨大的财富。因此，无论军方还是海盗，都在找寻着这座传说中的飞行岛。
```
```
　　矿工帕克这天偶遇拉比达继承人希达，两人一见如故。因为希达身上有找寻拉比达帝国的重要物件飞行石，军方和海盗两帮人马都在追杀希达。帕克带着希达一起逃亡，最终都没有逃出军方的手中，希达被军队掳走了。

### 菊次郎的夏天(Summer)
```
　　暑假到来，自幼丧父的小学三年级学生正男（关口雄介饰），如今和奶奶生活在一起，暑假特别无聊。他拿出母亲从外地寄回的信，准备自己一个人去爱知县丰桥市看望母亲。

### 土耳其进行曲(Mozart: Rondo Alla Turca)
```
　　《土耳其进行曲》来自莫扎特(Mozart)《A大调钢琴奏鸣曲》的第三乐章，但这一乐章常常被拿出来单独地弹奏。土耳其进行曲这个名字并不是莫扎特自己起的，而是因莫扎特在这一乐章标注了 “带有土耳其风格” （Alia Turca），并且乐曲主题有着鲜明的进行曲风格，故被大家称作土耳其进行曲。然而我们今天听来，这首乐曲并没有太多的土耳其风格。像18世纪后半期的许多欧洲人（特别是维也纳人）一样，莫扎特对于东方风情也是充满了好奇，甚至可以说是一种时尚，而这首土耳其进行曲更像是莫扎特对于土耳其的一种想象。
```
```
　　《土耳其进行曲》是最受小朋友喜欢的曲子，深入人心，广为流传。它节奏明快，旋律灵动，曲子本身就散发出活泼可爱，天真烂漫的气息，和孩子特别契合。> Marnie Laird 出生于 1983 年，生于加拿大，担任迈阿密新世界交响乐团的首席钢琴家。　　**Video:** [Marnie Laird - 土耳其进行曲(Rondo Alla Turca)](https://<!-- template: SERVERNAME -->/mwbbs/obj.php?p=video&f=piano/Marnie_Laird-Rondo_Alla_Turca.mp4)
```

### 钟(Liszt: La Campanella)
```
　　李斯特(Liszt)的《La Campanella》原为帕格尼尼的小提琴协奏曲，当时李斯特听到此曲后被深深吸引，随即改编为钢琴作品。此曲旋律优美动听，表达了李斯特当时的雄心壮志以及对未来事业的热切追求。> 　　李云迪(Yundi Li)，1982 年 10 月 7 日出生于中国重庆，国际钢琴家。
　　2000 年，李云迪获得第 14 届肖邦国际钢琴比赛冠军 & 最佳波兰舞曲演奏奖，成为首位获此奖项的中国人，以及历史上最年轻的冠军得主。2010年又获得全球“第一本肖邦护照”，2015年，受邀担任第17届肖邦国际钢琴比赛评委，成为此赛事史上最年轻的评委。肖邦国际钢琴比赛，不管是在“四个世界级钢琴比赛”，还是“国际十大钢琴比赛”，都名列第一，是名副其实的最顶级钢琴专业比赛。
```
```
　　发行的《肖邦精选》、《李斯特钢琴精选集》、《乐动柏林》、《贝多芬：悲怆·月光·热情》等 CD 唱片，获得诸多白金唱片、欧美年度最佳/年度唱片等奖项，以及《肖邦第一钢琴协奏曲》更是获得“企鹅唱片指南最高四星钥匙”专业顶级评价。
```
```
　　争议：有众多贴子言之凿凿说广大人民群众及国内音乐界的专家评价李的钢琴实际上也就那么回事，最好的时候是 2000 年，然后不管是以前，还是以后，都是走下坡路的——而且越来越厉害，以至于他们都听不下去的水平。
```
```
　　P.S. 这个就没办法评价了，每个人都有表达意见的权利。　　**Video:** [Yundi Li - 钟(La Campanella)](https://<!-- template: SERVERNAME -->/mwbbs/obj.php?p=video&f=piano/Yundi-Liszt-La_Campanella.mp4)
```

### 夜的钢琴曲五
```
　　石进写的钢琴曲没有多么精深、高妙，演奏起来也不需要什么高难度的技巧，但简简单单却打动了众多听众。
```
```
　　《夜的钢琴曲》是作者石进从 2006 年开始，历时 3 年半创作的 31 首乐曲。首首都是不同的心情，记录着一个又一个夜晚，欢乐的、忧伤的、难过的、当然也包括幸福的。夜的钢琴曲中的每一首曲子都静谧舒缓，让彼此心灵诗意地栖息。
```

### 月光(Debussy: Suite bergamasque, L.75: III)
```
　　《月光》是德彪西从 1890 年开始写作的钢琴组曲《贝加摩组曲》中第三乐章，是德彪西的代表作，正如罗曼·罗兰的赞誉他是“伟大的梦境画家”，他的音乐也如梦幻一般闪烁光与色彩。他以清谈的笔墨、朴素的音调，给人们描绘出一幅万籁俱寂、月光如洗的图画。> 　　郎朗(Lang Lang)，1982 年 6 月 14 日出生于中国辽宁省沈阳市，中国钢琴演奏者。
　　在中国是最具盛名的钢琴演奏者，联合国和平使者，还有众多的文化、形象、荣誉、旅游、巅峰、反诈宣传大使等头衔。在大陆有众多拥趸(其中有很多兼网络钢琴评论家)，视其为连对手都没有的第一，以至于连其父二胡、其妻钢琴也从名不见经传到倍受推崇。
```
```
　　演奏表现张力好，动作强大，表情异常丰富。往往还未开始弹奏，便深浸其中尔。
```
```
　　获奖基本上集中在“德国古典回声大奖”(N 次)，以及“意大利伽利略2000大奖”、“荷兰爱迪生音乐大奖”、“全英古典音乐奖年度最佳男艺术家”、“阿斯图里亚斯王子奖艺术奖”等不好确定专业水平的奖项。
```
```
　　争议：之所以未获得专业奖项，可能的原因是对此种需要证书证明的不屑，2000 几年前后即声称不参加任何此类专业比赛。
```
```
　　P.S. 郎朗的维基百科上存在“此条目需要补充更多来源”、“此条目疑似由大量爱好者内容组成”等问题。　　**Video:** [Lang Lang - 月光(Debussy: Suite bergamasque, L.75: III)](https://<!-- template: SERVERNAME -->/mwbbs/obj.php?p=video&f=piano/Lang_Lang-Debussy-月光.mp4)

### 叶塞尼亚(Yesenia)
```
　　风靡二十世纪七八十年代的墨西哥经典影片《叶塞尼亚》，拥有世界电影史上最经典的爱情对白，还有一代天才配音演员李梓俏皮而风情万种、乔榛稳重深沉而富有磁性的美妙配音。《叶塞尼亚》是心中一个难以忘怀的名字，它代表着一位美丽吉普塞女郎，一段浪漫的爱情故事，一个纯真年代留下来的珍贵记忆。
```
```
　　故事说的是19 世纪热情洋溢的墨西哥小镇，吉普赛女郎叶塞尼亚（杰奎琳·安德瑞 Jacqueline Andere 饰）高傲聪慧，宛若一株带刺的玫瑰。由于时常遭到白人的歧视，因此叶塞尼亚偶尔会偷钱惩治这帮势力眼。某天，叶塞尼亚在酒馆算命，结识了自信满满的白人军官奥斯瓦尔多（Jorge Lavat 饰）。勇敢的奥斯瓦尔多请求吉普赛头人同意他们的结合，在叶塞尼亚外婆的点拨和撮合下，最终如愿以偿。
```

### 小星星变奏曲 (Mozart: Ah vous dirai-je, Maman, K. 265/300e)
```
　　这是钢琴历史上不朽的作品之一。1778 年初夏，莫扎特(Mozart )停留巴黎时为一位女弟子而作。它的节奏与旋律单纯质朴，莫扎特为它配上十二段可爱又富有魅力的变奏，旋律流畅，变奏自然，是最富有莫扎特天使般童趣的作品之一。

### 雨的印记(Kiss The Rain)
```
　　雨的印记《Kiss The Rain》，出自韩国音乐家 YIRUMA 之手，电视剧《夏日香气》的背景钢琴曲。YIRUMA 写这首歌的时候，是在一个星星漫天的夜晚，忽然间一场大雨，把 YIRUMA 浇得如落汤鸡一般，于是乎让 YIRUMA 有感而发写下了 Kiss The Rain 这首曲子。曲调平静、温柔、细腻，具有的东方式的婉转。可能因为音乐家有古典音乐的底蕴，所以清新雅致的音乐中有着淡淡的忧郁色彩(也可能是确实淋的不轻)。

### 卡农(Johann Pachelbel - Canon in D Major)
```
　　D大调卡农(Canon and Gigue in D major for 3 violins and Basso Continuo)是巴洛克时期的音乐作品，创作于 1683 至 1690 年之间，三百多年了竟然魅力依旧。当年年轻的约翰·巴哈贝尔(Johann Pachelbel，德国音乐家，巴洛克中期南德管风琴学派的代表人物)，忍受着爱妻和儿子死于鼠疫的巨大痛苦，创作出一组不朽的音乐，以纾解心中的忧伤、纪念往逝的亲人。其中的一首变奏曲，就是后人所称的 D大调卡农（Canon in D Major）。
```
```
　　D大调卡农(Canon in D Major)不仅是现代人最喜爱的器乐作品之一，也是电影电视广告配乐的常客(《凡夫俗子》《我的野蛮女友》《金色琴弦》等)。原版由三把小提琴演奏，并以大键琴和大提琴及鲁特琴伴奏，节奏舒缓有序，旋律优美，每次听《卡农》，都会感到淡淡的忧伤和听到内心倔强的声音。
```
```
　　因为它是最著名的卡农乐曲，有时也常以“卡农”代指。然而实际上卡农（Canon）并非曲名，而是一种曲式。(就比如邦迪)
