二维码（2-dimensional bar code）是移动设备上很流行的一种编码方式，比传统的[[条形码|条形码（Bar Code）]]能存储更多的信息、表示更多的数据类型。二维码在代码编制上巧妙地利用构成计算机内部逻辑基础的 01 比特流的概念，使用若干个与二进制相对应的几何形体来表示文字数值信息，通过图像输入设备或光电扫描设备自动识读以实现信息自动处理。

1987 年 David Allair 研制了 Code49，Intermec 公司据此推出了世界上第一个二维码。Code49，又称行排式二维码、堆积式二维码或层排式二维码），其编码原理是在一维码基础之上，按需要堆积成二行或多行。

日本电装株式会社（Denso）工程师原昌宏（はら まさひろ, Hara Masahiro）从 1992 年开始二维码的研发工作，1994 年开发出 QR Code（Quick Response），1999 年通过 JIS 标准，2000 年通过 ISO 标准。获得 2002 年 R&D 100 奖（美国），2004 年移动项目奖大奖，2007 年日本创新者奖，2012 年优良设计奖 Best100 和 2014 年欧洲发明家奖大众奖等众多奖项。原昌宏也被人称为“二维码之父”。

QR Code 是一种矩阵二维码符号，在横向和纵向都可以记录信息的二维码技术。除具有信息容量大、可靠性高、可表示汉字及图像多种文字信息、保密防伪性强等优点外，还可高效地表示汉字，相同内容，其尺寸小于相同密度的 PDF417 条码。市场上的大部分条码设备都支持 QR Code条码。

QR Code 即使整个代码的 30% 被损坏，仍然可以读取正确的信息。代码中 60% 以上的数据被冗余数据所占用，通过包含数学的“错误修正”，能够从没有破损的部分推测欠缺的部分。

QR Code 的最大符号大小为 177x177 块。具有 31,329 个方格，可以编码 3KB 的数据。这意味着 QR 码数据大小总共为 7,089 个数字字符或 4,269 个字母数字字符。1,817 个汉字/假名字符。

常用的二维码有行排式（Code 49、PDF417、Code 16K）、矩阵式（QR Code、Code One、MaxiCode、Data Matrix、Han Xin Code、Grid Matrix）等。

### Web

使用 [qrcode.min.js](https://github.com/davidshimjs/qrcodejs) 可以在网页上生成并显示二维码。
 ```
Javascript QRCode
QR
var qrcode = new QRCode(document.getElementById("qrcode"), {
	width : 300,
	height: 300
});
function makeCode() {
    var fileName = document.getElementById("text").value;
    var filePath = `QR/${fileName}.conf`;
    fetch(filePath)
        .then(response => {
            if (!response.ok) {
                throw new Error('File not found');
            }
            return response.text();
        })
        .then(data => {
            qrcode.makeCode(data);
        })
        .catch(error => {
            if (error.message === 'File not found') {
                qrcode.makeCode(fileName);
            } else {
                console.error('Error reading file:', error);
                alert('ER');
            }
        });
}
makeCode();
```

### Ubuntu

使用 qrencode 可以在 Linux 下生成及显示二维码。
```
 # apt install qrencode
 cat ${FN} | qrencode -o - -t UTF8  # 命令行窗口显示
 cat ${FN} | qrencode -o u01.png    # 生成图片
```
