```
　　《从一到无穷大》是一本妙趣横生的科普著作，内容涉及自然科学的方方面面。通过数学，把物理、化学乃至天文学、地质学、生物学、以致遗传密码的许多前沿内容有机地融合在一起。让人们了解到那些枯燥的数学公式、物理概念、化学符号之间，有那么多有趣的故事；那无穷大的宇宙、无边无际的遥远星系，并不是跟我们毫无关联；
```
```
　　这本书应该是八六年的时候读的，当时印象深刻的除了印度国王被国际象棋的发明人摆了一道，欠下了全世界有史以来生产的所有的麦粒，再有就是有着无限房间的希尔伯特旅店......还有对于四维空间的概念也应该是来自于这本书......
```
```
　　这本书与《物理世界奇遇记》的中译本是自然科学入门的经典作品，几乎可以说是影响了七八十年代的一代人。>
```
