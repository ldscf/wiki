```
　　内功，大家都不陌生，看武侠小说时经常遇到。一些封建迷信的人就说了，那是小说家蒙人滴，不要相信~~错！大错！！
```
```
　　我们不要人云亦云，要与时俱进，以发展的、科学的、大众的眼光来分析内功这个神秘的东东。
```
```
　　科学的分析如下：
```
```
　　据现代医学解剖发现，人体内的神经传导靠的是动作电位，也就是因为神经细胞内外的NA+和K+离子存在着浓度差，在电位传来的一瞬间，离子通道的开闭问题。所以我们可以简单的得出第一个结论：
```
```
　　1：离子浓度的差异，在体内可以产生生物电。
```
```
　　然后是内功，内功的科学发现，是按经络分布的，大体位置在淋巴节的附近。据对气功大师的X光等光的照射表明，大师发功的时候，明显有大量红外线，X光和其他射线产生。于是得出第二个结论：
```
```
　　2：内功的表现往往是种波。
```
```
　　综上，我们可以大胆设想，得出如下结论：
```
```
　　一：人经过长时间专门的修炼，使自己内分泌系统产生定向的变化，就会使得体内体液的分布，或浓度有着某种特殊的方式分布，这样，在一定的激发条件下，体液由于浓度的改变，可以产生大量的生物电，生物电再以波的形式发出。
```
```
　　二：由于波的大小和性质的不同，所以内功的表现也不同，功力大了，距离就远了，就可以隔山打牛了。
```
```
　　三：所谓练功的口诀，姿势，就是为了保证体液的位置到位~~产生固定的电势差。同理可知，为什么固定武功需要固定的内功。
```
```
　　四：那个什么走火入魔就是内分泌失调了。
```
```
　　五：打通经脉就是为了体液的定向流淌。
```
```
　　六：吃什么仙丹、桃子、蛇胆、吉野家，就是迅速大量的补充体液。
```
```
　　七：练功冒烟是为了排出无用的离子，由于离子不同颜色也不一样，一般大家都是排水——白色，比如紫霞功，估计是排出K+离子，所以发紫。
```
```
　　大众结论：其实这个淫呢，就是一特大号滴电池，内功就是电，你内功高了就是南浮的电池，电量就大，也就比较牛B懂了不~~
```
