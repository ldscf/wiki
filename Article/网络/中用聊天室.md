```
    一、新用户可以注册自已的昵称，一旦注册，此昵称在此聊天室内全权属你，注册时可填入有关资料，让大家了解你，并可随时更新。
```
```
    二、注册用户每停留一分钟，经验值增加一点（必须在聊完天后按“离开聊天”离开本室，系统才会统计），经验值高者可自动升级，达到一定级别，同时如果拥有良好的群众基础，可以向网管申请进入“联防保安队”并同时拥有人员管理权限。注意：请勿作弊，系统会智能监测并向管理员报告。
```
```
    三、新版聊天室有提供多项功能，全面照顾各位网友：
```
```
      1、画面过滤功能：当你觉得某个聊友言谈不适合你时，你可使用此功能把其过滤，这样你就不会再看到其说话，当然其他人还是照常能看见此人的谈话的。这项功能向所有注册用户开放。
```
```
      2、约会留言功能：当你觉得有需要向某个聊友提出约会时，可用此功能留言。
```

```
      5、踢人功能：请勿违反聊天礼仪，否则会被广场保安踢出，30分钟后才能重新登录。同时拥有踢人权限的用户不能随意滥用踢人权限，否则将被作降级处理。
```
```
      6、免打扰功能：选中免打扰，与自己无关的发言将不会显示，让您聊得更顺手。
```
