《向左走，向右走》(Turn Left, Turn Right)，是台湾小说家几米创作的绘本小说，海豚出版社于2002 年 8 月出版，126页，￥38。

《向左走，向右走》是都市里的故事，是一本几米献给那些注定相遇的人的书。

![向左走向右走.jpg](https://mwbbs.eu.org/wiki/images/5/51/向左走向右走.jpg)

几米，绘本作家。1998 年开始创作，著有《听几米唱歌》《镜子里的小孩》《地下铁》《幸运儿》《微笑的鱼》《向左走向右走》等30多种作品，并已有美、法、德、希腊、韩、日、泰等国的译本。多部作品改编为音乐剧、电视剧和电影，动画《微笑的鱼》荣获2006年柏林影展国际评审团特别奖。2007年几米本人被 Discovery 评为“台湾人物志”六位杰出人物之一。

梁咏琪、金城武领衔主演的同名影片于 2003 年 9 月 11 日上映。

*她决定离开这个荒寒的城市，他决定到一个阳光灿烂的地方去旅行。天空开始变得晴朗，远方飘来平安夜悠扬的歌声。*

> **看几米的《向左走向右走》**
```
　　大多数的童话故事，都有个王子和公主从此过上了幸福生活或者类似于此的美好的结局。《向南走向北》...不好意思，是《向左走向右走》也是这样。在两个人都想放弃的时候，他们竟然又相遇了。
```
```
　　统计了一下这篇故事里这种偶然，发现从故事的开始，到结局，这种情况下出现的概率大约是千万分之一。(用到的是概率论里面的相乘法则，因为这两个家伙如果不一个向左一个向右，那么他们就用不着在公园相遇了，同样，天天见面的人，也用不着因为想见而见不到，而同时想放弃；不放弃的话，照他们那个习惯也不会再相遇。每个事件的发生概率从略，详情请拨打本地 114 咨询。
```
```
　　既然发生的概率是如此之低，那么为什么还要去幻想着相遇？
```
```
　　还是走每天走的老路，不去关心路旁的草绿了，树出芽了还是花开了。去做应该做的事，不去改变习惯，也不去幻想遇见什么人。
```
```
　　也许有缘的话，相遇了就相遇了。就算是再也见不到了，又有什么关系？在这个世界上，有太多的人我们不相识；有太多的事我们不懂。
```
```
　　相见了，值得小心呵护。错过了，也不必惋惜。
```
```
　　也许错过的终究要错过。只不过，偶尔想起来，会感动一下。
```
```
　　其实，我们相识的每一个人，都是一种缘。生你养你的父母，从小到大的朋友，同学同事同乡...，如果你晚一点从天国到这个世界，那么可能遇到的就是另一些人。不去珍惜身边的、应该珍惜的缘分，而幻想着那种根本不会发生的缘分，是一种天真和无知。
```

后记(补充)：
```
　　我个人认为，在几米先生的作品《向左走向右走》里发生的故事是个极低概率事件。是继古代公主的美好童话、琼瑶女士骗少年少女的理想故事及痞子蔡先生的 e 爱情之后的后幻想主义文学——即由一系列的低概率事件组合在一起，而产生的一种半臆想的爱情小说。
```
```
　　类似于大盘以一种很规则的正弦曲线，跌宕起伏，在以井喷式的涨停后结束。于是广大的股民同志们就以为大盘以后就会以“下抛物曲线”方式连续的涨停了。
```
```
　　其实，我觉得广大的人民群众更会是一种正态分布式的方式来进行他们一生的爱情，符合 2/8 规则。即：在 20% 的时间里，发生超过 80% 的爱情故事。而在那 80% 的时间里，只有不到 20% 的爱情。
```
```
　　其曲线应该为：以结婚为界，其前，是一种振幅不断增强的类正弦曲线。其后，曲线的振幅会不断减弱。
```

阿奔  2003/4/1
