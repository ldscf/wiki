## 基本语法

一般在设定标题前，会有一段说明文字及图片，以作为预览之简介，如本文档：[[Help|帮助]]

### 目录

超过三个以上标题时目录会自动显示，但也可以强制显示：

强制显示目录：__TOC__、不显示目录：__NOTOC__

### 分类

“Category”命名空间中包含分类——也就是其它页面的动态列表。

代码[[Category:Help]]将在页面底部（位于底部被标记为“分类”的文本框中）产生一个分类链接。 单击链接可以跳转到分类页面，并且，当前页面将出现在其中的页面列表中。

每个文档均需要加入类型，如本文档：

[[分类:Doc]]

[[分类:Help]]

### 清除被删文件

MediaWiki 的维护脚本需要在控制台下运行，其位于/wiki目录/Maintenance/

*删除被删文件
```
 php deleteArchivedFiles.php --delete
```

*删除被删版本
```
 php deleteArchivedRevisions.php --delete
```

### 清除文件修改历史

用 admin 删除文件，再选择恢复最后版本即可。
