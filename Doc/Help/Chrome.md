Google Chrome 的诞生和发展是现代互联网历史上的一个重要事件，它深刻地改变了浏览器市场格局和 Web 技术的发展方向。

在 21 世纪初，微软的 Internet Explorer (IE) 占据绝对主导地位，Mozilla Firefox 作为开源替代品逐渐崛起。WEB 服务功能越来越多越来越像复杂的桌面应用程序，对浏览器的性能、稳定性和安全性提出了更高的要求，而当时的浏览器在处理复杂的 Web 应用时显得有些力不从心。

Google 认为 Web 本身就是一个平台，需要一个更现代、更快速、更稳定的浏览器来支撑 Web 应用的发展。他们希望浏览器不仅仅是内容的展示器，更是一个运行复杂应用的操作系统。于是 Google 组建了一个团队，聘请了一些前 Mozilla Firefox 的开发者，开始研发自己的浏览器。
1. 2008 年 9 月 2 日，Google 发布 Google Chrome 的第一个 Beta 版本 (仅限 Windows)
1. 2010 年：发布 Mac 和 Linux 的稳定版本
1. 2012 年：发布 Chrome for Android
1. 2012 年：发布 Chrome for iOS

凭借其速度、简洁、安全和不断增加的功能，Chrome 的市场份额迅速增长，最终在 2012 年超越了 Internet Explorer，成为全球市场份额第一的浏览器。

### chrome 扩展

chrome 扩展(chrome extensions)是 chrome 应用商店中的程序，用于增强 Chrome 浏览器功能。> <https://chrome.google.com/webstore/>(https://chrome.google.com/webstore/category/extensions)

#### OneNote Web Clipper

微软 OneNote 记事本，可将网络上的任何内容保存到 OneNote。将其剪贴到 OneNote 中、进行整理和编辑，然后通过任何设置进行访问。
- 整页（截长屏）、区域（截屏）、文章/PDF、书签
- 网页上的任意图像以及 YouTube 或 Vimeo 视频
- 某些类型页页无法剪贴，如：chrome extensions 页面就无法剪贴
