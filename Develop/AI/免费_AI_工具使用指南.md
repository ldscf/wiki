### Web AI

#### ChatGPT

简介：

OpenAI 提供的通用 AI 助手，免费版本支持文本对话、代码生成、文件分析等能力。

优点：
- 综合能力强
- 推理能力优秀
- 编程辅助能力强
- 支持多模态输入

> 访问：

https://chatgpt.com/适合使用场景：
- 技术咨询
- 软件设计
- 编程辅助
- 文档编写
- 学习辅助

#### Gemini

简介：

Google 开发的多模态 AI 助手，支持文本、图片、代码等输入。

优点：
- 免费额度较高
- 多模态能力优秀
- 长上下文能力强
- 集成 Google 生态

> 访问：

https://gemini.google.com/适合使用场景：
- 技术研究
- 文档分析
- 信息查询
- 学习辅助

#### Grok

xAI 开发的 AI 助手，支持实时信息查询和创意生成。

优点：
- 实时信息能力较强
- 创意能力较好
- 对话风格开放

> 访问：

https://grok.com/适合使用场景：
- 新闻查询
- 创意写作
- 日常问答

### AI Agent

#### OpenCode

简介：

开源 AI 编码 Agent 平台，提供完整的软件开发辅助能力。

OpenCode 面向开发者设计，可以理解代码仓库、执行开发任务，并支持多种 AI 模型工作方式。

特点：
- 开源
- 支持多种模型
- 提供完整 Agent 工作流
- 支持代码仓库级理解
- CLI 工作方式适合工程开发
- 适合大型项目维护

> 访问：

https://opencode.ai/

源码：

https://github.com/opencode-ai/opencode适合使用场景：
- 软件开发
- 项目分析
- 代码重构
- Bug 修复
- 自动化开发任务

推荐：

OpenCode 作为日常 AI 编程主入口。

#### Free-Claude

简介：

开源 Claude Code 类 AI 编码方案，提供免费的 Agent 使用方式。

Free-Claude 通过集成免费模型服务，实现类似 Claude Code 的开发体验。

特点：
- 免费使用 AI 编码 Agent
- 支持代码理解和修改
- 支持模型切换
- 接近 Claude Code 工作流程
- 可结合 NVIDIA NIM 提升模型能力

> 

源码：

https://github.com/alishahryar1/free-claude-code

适合使用场景：
- AI 辅助编程
- 自动生成代码
- 项目重构
- 代码分析

推荐组合：

Free-Claude

+

NVIDIA NIM

优势：
- 免费 Agent 工作流
- 更强模型推理能力
- 适合复杂代码任务

#### Agnes Code

简介：

Agnes AI 提供的 AI 编程工作台，提供图形化 AI Agent 开发体验。

特点：
- GUI 操作界面
- 支持项目接入
- 支持 AI 工作流
- 降低 Agent 使用门槛

> 访问：

https://agnes-ai.com/agnescode

适合使用场景：
- 软件开发
- 项目分析
- AI 辅助编码
- 自动化任务

### AI API

#### NVIDIA NIM

简介：

NVIDIA 提供的大模型推理服务平台，为 AI 应用和 Agent 提供模型能力。

NVIDIA NIM 支持多种高性能模型，并提供比较宽松的免费开发额度。

特点：
- OpenAI API 兼容
- 支持多种模型
- 免费额度可用于开发测试
- 适合 AI Agent 调用

> 

访问：

https://build.nvidia.com/

适合使用场景：
- Free-Claude 模型增强
- AI Agent 后端
- 编程助手
- 模型测试

推荐：

Free-Claude

+

NVIDIA NIM

- 免费 Agent
