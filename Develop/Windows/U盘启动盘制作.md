推荐使用 Rufus，其他常用工具有老毛桃、大白菜等。

### [Rufus](https://rufus.ie/downloads/)
```
 Rufus 是一款格式化和创建 USB 启动盘的辅助工具，适用于以下场景：
```
- 将可引导 ISO (Windows、Linux、UEFI 等) 刻录到 USB 安装媒介
- 处理未安装操作系统设备
- 在 DOS 环境下刷写 BIOS 或其他固件
- 运行底层工具

P.S. 安装 Windows 11 若硬件不符合要求，使用 Rufus 创建 USB 启动盘时，可以选择 Remove requirement for 4GB+RAM, Secure Boot and TRM 2.0。
