获取 C++ 各种容器和 C 风格数组的大小，在 C++17 以前并没有标准库函数 size()，所以需要使用 C++ 模板高级特性（SFINAE 和非类型模板参数）来实现。

### 函数模板和重载
 ```
// get_size
// size()
template 
auto get_size(const Container& c) -> decltype(c.size()) {
    return c.size();
}
// C Array
template 
size_t get_size(const T (&)[N]) {
    return N;
}
```

### C++17
 ```
#include  // For std::size (C++17)
std::size(obj)
```

### 说明
1. **template** : 声明模板，用 typename 定义类型参数（在早期版本 C++98/03 中，使用 class 关键字。例如 template ）。主要作用是实现泛型编程（Generic Programming）————能够处理多种不同的数据类型。模板在编译时进行实例化和特化。这意味着类型检查和函数绑定都在编译阶段完成，而不是运行时，这通常比运行时多态（如虚函数）具有更好的性能。
1. **auto get_size(const Container& c) ->** : auto 表示函数的返回类型将由 -> 符号后面表达式推导出来，是 C++11 引入的尾随返回类型语法。
1. **decltype(c.size())** : 这个表达式的意思是 c.size() 表达式的类型是什么。标准库容器有 size() 成员函数，所以对于标准库容器，可以得到其类型。而当传入 C 风格数组时，因为 C 风格数组没有 size() 成员函数，所以这是一个非法的表达式。此时 C++ 的 SFINAE(Substitution Failure Is Not An Error)原则发挥作用————如果模板参数推导过程中导致无效的构造，那么这个特定的模板实例会从重载决议的候选中被移除，而不是导致编译错误。
1. **const T (&)[N]** : 这个模板的关键之处是它声明了一个非类型模板参数 N，这个参数是一个对固定大小的 C 风格数组的常量引用。当编译器看到一个 C 风格数组时（如 int arr[10];），会神奇地推导出 N 为 10（ T 为 int 并不奇怪，本来就是模板的特性）。
