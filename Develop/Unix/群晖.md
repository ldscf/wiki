### 简介

群晖 NAS (Synology) 是一款基于 Linux 内核的专用网络存储服务器系统（DSM，DiskStation Manager）。在多服务器与后端架构开发环境中，群晖通常被定位为：
- 私有部署的存储中枢：用于存放离线异地备份、大型数据集或中间构建产物。
- 轻量级服务宿主机：内置 Git Server，并原生支持 Docker/Container Manager，可低成本部署私有镜像仓库或测试基座。
- 核心研发防线：通过严苛的底层权限管理，承载团队核心数字资产的防守任务。

### 证书登录

群晖 DSM 系统的权限默认配置极其奇怪，如对家目录权限的极度放宽导致公钥失效并退化为密码登录。

这是群晖最核心的踩坑点。必须登录群晖物理隔离区，将权限收紧至合规状态，否则 sshd 服务会出于安全防范直接物理拒绝公钥。
 ```

# 用密码登录群晖环境
ssh xxx@192.168.0.10

# 赋权
chmod 700 ~
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys
```

### 其他

#### 内置 Git 仓库的安全审计

如果通过群晖 Git Server 插件管理代码，其远程仓库的规范路径通常挂载在存储卷上：
- 路径：xxx@192.168.0.10:/volume1/Git/AdminSupport/teset.git
- 其他：

:# 只要打通了上述的 SSH 证书登录，本地执行 git push 或 git pull 将自动实现非对称加密握手

:# 严禁将含有明文密码的 HTTPS 链接写入仓库配置。

#### 容灾备份 (Hyper Backup)

利用群晖的 Hyper Backup 策略，将 /volume1 核心代码库与配置文件，定期执行异地或多卷增量备份，防止发生不可抗力物理损坏
