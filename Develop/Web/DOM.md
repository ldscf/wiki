DOM 是文档对象模型（Document Object Model）的缩写。它是一个跨平台、独立于语言的编程接口，将 HTML 或 XML 文档表示为一个树形结构。
1. D（文档，Document）：HTML 网页就是一个文档
1. O（对象，Object）：HTML 中的每个元素（标签、属性、文本）都被表示为一个对象
1. M（模型，Model）：这些对象按照层次关系组织成一个结构化的模型

### 概念

#### 1. 节点类型

DOM 树中的每个点都是一个节点，主要有以下几种类型：
- 元素节点：HTML 标签，如 <div>, <p>, <a>
- 文本节点：标签内的文本内容
- 属性节点：标签的属性，如 href="...", class="..."

#### 2. 节点关系
- 父节点：直接包含当前节点的节点
- 子节点：被当前节点直接包含的节点
- 兄弟节点：拥有相同父节点的节点
- 祖先节点：父节点、祖父节点等所有上层节点
- 后代节点：子节点、孙子节点等所有下层节点

示例（参考下面的 HTML）：
- <div> 是 <p> 和 <a> 的 父节点
- <p> 和 <a> 是 <div> 的 子节点，彼此是 兄弟节点
- <html> 是所有其他元素的 祖先节点
- <p> 内的文本是 <body> 的后代节点

### Example

#### HTML
 ```
<!DOCTYPE html>
 
 
     我的网页
 
 
     欢迎光临</h1>
     
         这是一个段落
         链接
     
 
 
```

#### DOM 树形结构
 ```
文档 (Document)
 │
 └── html (根元素)
     │
     ├── head
     │   │
     │   └── title
     │       │
     │       └── "我的网页" (文本节点)
     │
     └── body
         │
         ├── h1
         │   │
         │   └── "欢迎光临" (文本节点)
         │
         └── div (class="content")
             │
             ├── p
             │   │
             │   └── "这是一个段落" (文本节点)
             │
             └── a (href="https://example.com")
                 │
                 └── "链接" (文本节点)
```
