RSS：物理内存使用量（KB）

smem -t -U hdfs -k  # 显示用户进程内存占用

smem -k -r -s rss -r    # 按 RSS 倒排序

| CMD | Option | Sample | Memo |
|:---|:---|:---|:---|
| + |
| top | +m 按内存排序 |
| free | free -h |
| ps | aux | ps aux --sort=-%mem | head -n 10 | %MEM：内存使用百分比 |
| ps | eo | ps -eo pid,ppid,cmd,%mem,%cpu --sort=-%mem | head -n 10 |
| smem | smem -t -u -k          # 按用户显示总内存占用 |
| [pmap](#pmap) | x | X | pmap -x <PID> | sort -k4rn | head -n 11 |
