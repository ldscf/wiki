命令行（Command Line）是一种通过文本指令与计算机交互的界面。用户在命令提示符下输入命令，系统解析并执行，从而完成文件管理、程序运行、系统配置等操作。它是图形界面（GUI）出现之前计算机的主要交互方式，至今仍是开发、系统管理与自动化的重要工具。

### 命令行环境

**Linux**
- Shell（终端）：最常用的是 bash（Bourne Again Shell），其他常见的有 zsh、csh 等

**Windows**
- CMD（命令提示符）：最早的命令行环境，兼容 DOS 命令，如 dir、copy
- PowerShell：现代化命令行与脚本环境，支持对象传递（非纯文本），命令以动词-名词形式命名，如 Get-Process、Set-Date

**macOS**
- 基于 UNIX 架构，命令行与 Linux 高度相似。默认终端环境：zsh（自 2019 年 macOS Catalina 发布时起取代 bash）

### 变量

| OS | 定义 | 引用 | Memo |
|:---|:---|:---|:---|
| + |
| rowspan="2" | Linux/macOS | name="Alice" | $name | = 两边不能有空格，使用花括号避免歧义  ${name}_test |
| export PATH=/usr/local/bin:$PATH | $PATH | 子进程可见 |
| Windows | set name=Alice | %name% |
| rowspan="2" | PowerShell | $name = "Alice" | $name |
| $env:var = "abc" | $env:var | 子进程可见 |

#### 特殊变量

| OS | 变量 | 含义 | Memo |
|:---|:---|:---|:---|
| + |
| rowspan="5" | Linux | $0 | 当前脚本名 |
| $1、$2... | 命令行参数 | 空格分隔 |
| $# | 参数个数 |
| $? | 上一命令返回值 |
| $$ | 当前进程 ID |
| Windows | %USERNAME% | 当前用户名 |
| %ERRORLEVEL% | 上一命令返回码 |
