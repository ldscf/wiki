Nano 是 Linux 中最简单直观的命令行文本编辑器。界面底部自带快捷键提示，其中的 ^ 代表 Ctrl 键。

### 打开
- nano filename.txt

### 编辑

直接输入，方向键移动光标。
- 保存文件：Ctrl + O  

按后下方会提示确认文件名，直接按 Enter（回车）确定保存。
- 退出编辑器：Ctrl + X  

如果未改动，直接退出；若改动过，会询问是否保存（输入 Y 保留改动，或输入 N 放弃改动）。
- 快捷保存并退出： Ctrl + O -> Enter -> Ctrl + X

**常用辅助快捷键**
- 剪切一行：Ctrl + K
- 粘贴一行：Ctrl + U
- 搜索文本：Ctrl + W（Alt + W -> 下一个）
- 取消/返回：Ctrl + C（如果在提示界面中想取消当前操作）
